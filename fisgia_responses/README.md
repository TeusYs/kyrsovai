# Формат файла verifications_result.csv

Файлы в этой папке автоматически обрабатываются системой каждые 5 минут.

## Формат файла

CSV файл с разделителем `;` (точка с запятой) и следующими колонками:

### Обязательные колонки:
- `id_abit` - ID абитуриента в системе
- `result` - Результат проверки: `accepted` (принято) или `rejected` (отклонено)
- `comment` - Комментарий от ФИСГИА

### Опциональные колонки (для автоматического заполнения данных):
- `snils` - СНИЛС абитуриента (если проверен и корректен)
- `pasp_ser` - Серия паспорта (если проверена и корректна)
- `pasp_num` - Номер паспорта (если проверен и корректен)

## Пример файла

```csv
id_abit;result;comment;snils;pasp_ser;pasp_num
8;accepted;ОК;123-456-789 01;1234;567890
11;accepted;Данные проверены;987-654-321 02;5678;123456
12;rejected;Неверный формат СНИЛС;;;
```

## Как это работает

1. ФИСГИА создаёт файл `verifications_result.csv` в папке `fisgia_responses/`
2. Система автоматически (каждые 5 минут) сканирует эту папку
3. Для каждого абитуриента в файле:
   - Обновляется статус `VerificationRequest` (accepted/rejected)
   - Если указаны `snils`, `pasp_ser`, `pasp_num` - они автоматически заполняются в профиле абитуриента
4. Обработанный файл перемещается в папку `fisgia_responses/processed/` с временной меткой

## Важно

- Файл должен иметь заголовки (первая строка)
- Если данные паспорта/СНИЛС не указаны, поля остаются пустыми
- После обработки файл автоматически перемещается в `processed/`
- Если файл содержит ошибки, он не будет перемещён
