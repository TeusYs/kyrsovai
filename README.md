# Система приёма документов

Веб-приложение для управления процессом приёма документов абитуриентов в образовательное учреждение.

## Описание

Система предназначена для автоматизации процесса приёма документов и заявлений от абитуриентов. Включает функционал для:
- Регистрации и верификации абитуриентов
- Подачи заявлений на направления подготовки
- Проверки документов специалистами приёмной комиссии
- Интеграции с ФИСГИА для экспорта данных
- Поиска и фильтрации абитуриентов

## Технологии

- **Backend**: Django 5.2.8
- **API**: Django REST Framework
- **База данных**: SQLite (для разработки), PostgreSQL (для продакшена)
- **Frontend**: HTML, CSS, JavaScript
- **Python**: 3.11+

## Установка и настройка

### Требования

- Python 3.11 или выше
- pip
- Виртуальное окружение (рекомендуется)

### Установка

1. Клонируйте репозиторий или распакуйте архив проекта

2. Создайте виртуальное окружение:
```bash
python -m venv venv
```

3. Активируйте виртуальное окружение:
   - Windows:
   ```bash
   venv\Scripts\activate
   ```
   - Linux/Mac:
   ```bash
   source venv/bin/activate
   ```

4. Установите зависимости:
```bash
pip install django==5.2.8
pip install djangorestframework
pip install python-dotenv
```

5. Создайте файл `.env` в корне проекта (если его нет):
```env
SECRET_KEY=your-secret-key-here
DEBUG=True
```

6. Примените миграции:
```bash
python manage.py migrate
```

7. Создайте суперпользователя (опционально):
```bash
python manage.py createsuperuser
```

8. Запустите сервер разработки:
```bash
python manage.py runserver
```

Приложение будет доступно по адресу: http://127.0.0.1:8000/

## Основные модели данных

### Applicant (Абитуриент)
- Основная информация об абитуриенте (ФИО, контакты, паспортные данные)

### Program (Направление подготовки)
- Информация о направлениях подготовки (код, название, срок обучения)

### UploadedDocument (Загруженный документ)
- Документы, загруженные абитуриентом (паспорт, СНИЛС, образование, квоты, достижения)
- Статусы: pending, approved, rejected

### Application (Заявление)
- Заявления абитуриентов на поступление
- Статусы: на проверке, принято, отклонено

### StrokiZayav (Строки заявления)
- Детали заявления (направление, приоритет, тип образования)

### VerificationRequest (Запрос верификации)
- Запросы на верификацию документов через ФИСГИА
- Статусы: new, sent, accepted, rejected

### ApplicationRequest (Запрос заявления)
- Запросы на отправку заявлений в ФИСГИА
- Статусы: new, sent, accepted, rejected

## Функциональность

### Для абитуриентов

1. **Регистрация и вход**
   - Регистрация с указанием роли (абитуриент/специалист)
   - Вход в систему

2. **Верификация документов**
   - Загрузка обязательных документов (паспорт, СНИЛС, образование)
   - Загрузка дополнительных документов (квоты, достижения)
   - Отслеживание статуса проверки документов
   - Просмотр причин отклонения документов

3. **Подача заявлений**
   - Подача заявления на направление подготовки
   - Выбор формы обучения (очная/заочная)
   - Выбор типа обучения (бюджет/контракт)
   - Указание приоритета и комментария
   - Просмотр списка поданных заявлений
   - Отзыв заявления

4. **Просмотр списков**
   - Просмотр списков направлений
   - Просмотр списков абитуриентов по направлениям (только принятые)

### Для специалистов

1. **Проверка документов**
   - Просмотр неподтверждённых документов
   - Одобрение/отклонение документов с указанием причины
   - Просмотр всех документов
   - Просмотр подтверждённых и отклонённых документов

2. **Управление заявлениями**
   - Просмотр заявлений по направлениям
   - Изменение статуса заявления
   - Просмотр детальной информации о заявлении

3. **Запросы и поиск**
   - Получение списка всех абитуриентов, подавших документы
   - Поиск абитуриента по ФИО/ID
   - Получение контактных данных абитуриента
   - Поиск по периоду подачи документов
   - Поиск по специальности/направлению
   - Поиск абитуриентов с достижениями (ГТО, волонтёрство)

## API

Система предоставляет REST API через Django REST Framework:

- `/api/applicants/` - API для абитуриентов
- `/api/programs/` - API для направлений
- `/api/applications/` - API для заявлений
- `/api/achievements/` - API для достижений
- `/api/applicant_achievements/` - API для достижений абитуриентов
- `/api/stroki_zayav/` - API для строк заявлений

## Настройка базы данных

По умолчанию используется SQLite. Для продакшена рекомендуется PostgreSQL.

В `settings.py` измените настройки базы данных:

```python
DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.postgresql',
        'NAME': 'your_db_name',
        'USER': 'your_db_user',
        'PASSWORD': 'your_db_password',
        'HOST': 'localhost',
        'PORT': '5432',
    }
}
```
