## Начало работы

### Регистрация

1. Откройте страницу регистрации
2. Выберите вашу роль:
   - **Я абитуриент** - если вы поступаете
   - **Я сотрудник приёмной комиссии** - если вы специалист
3. Заполните форму:
   - Email (будет использоваться как логин)
   - Пароль
   - Повторите пароль
   - Если вы абитуриент, заполните дополнительные поля:
     - Фамилия, Имя, Отчество
     - Телефон
     - Пол
     - Дата рождения
4. Нажмите "Зарегистрироваться"

### Вход в систему

1. Откройте страницу входа
2. Выберите вашу роль
3. Введите email и пароль
4. Нажмите "Войти"

## Руководство для абитуриентов

### Главная страница

После входа вы попадёте на страницу "Мои заявления", где отображаются:
- Статус верификации ваших документов
- Список поданных заявлений

### Верификация документов

**Важно**: Подача заявлений возможна только после прохождения верификации документов.

#### Шаг 1: Загрузка документов

1. Перейдите в раздел **"Верификация"**
2. Загрузите обязательные документы:
   - **Паспорт** - изображение паспорта
   - **СНИЛС** - изображение СНИЛС
   - **Документ об образовании** - аттестат или диплом
3. При необходимости загрузите дополнительные документы:
   - **Документ для квоты** - если вы претендуете на квоту
   - **Документ о достижениях** - ГТО, волонтёрство и т.д.
4. Нажмите "Отправить документы"

#### Шаг 2: Ожидание проверки

После загрузки документы отправляются на проверку. Вы увидите статус:
- **На проверке** - документы проверяются специалистом
- **Подтверждён** - документы приняты
- **Отклонён** - документы отклонены (будет указана причина)

#### Шаг 3: Исправление отклонённых документов

Если документ был отклонён:
1. Просмотрите причину отклонения в таблице документов
2. Загрузите исправленный документ
3. Дождитесь повторной проверки

**Примечание**: Предупреждение об отклонённых документах автоматически исчезнет, когда вы загрузите новую версию и она будет подтверждена.

### Подача заявления

После прохождения верификации вы можете подать заявление.

1. Перейдите в раздел **"Подача заявления"**
2. Заполните форму:
   - **Направление подготовки** - выберите из списка
   - **Форма обучения** - очная или заочная
   - **Тип обучения** - бюджет или контракт
   - **Тип образования** - основание приёма
   - **Приоритет** - номер приоритета (1, 2, 3...)
   - **Комментарий** - необязательное поле
3. Нажмите "Отправить заявление"

**Примечание**: Форма автоматически заполняется данными из вашего последнего заявления (кроме приоритета и комментария).

### Мои заявления

В разделе **"Мои заявления"** вы можете:
- Просмотреть все поданные заявления
- Увидеть статус каждого заявления
- Отозвать заявление (кнопка "Отозвать")

**Внимание**: Отзыв заявления удаляет его полностью. Это действие нельзя отменить.

### Просмотр списков

В разделе **"Все списки"** вы можете:
- Просмотреть все доступные направления подготовки
- Открыть список абитуриентов по выбранному направлению
- Увидеть только абитуриентов со статусом "принято"

## Руководство для специалистов

### Главное меню

После входа специалист имеет доступ к следующим разделам:
- Неподтверждённые абитуриенты
- Подтверждённые абитуриенты
- Абитуриенты с неправильными документами
- Все документы
- Статусы заявлений
- Запросы
- Настройки

### Проверка документов

#### Неподтверждённые абитуриенты

1. Перейдите в раздел **"Неподтверждённые абитуриенты"**
2. Вы увидите список абитуриентов с документами на проверке
3. Нажмите на email абитуриента для просмотра документов

#### Проверка документов абитуриента

1. На странице проверки документов вы увидите:
   - Информацию об абитуриенте
   - Таблицу загруженных документов
   - Статус каждого документа
2. Для каждого документа доступны действия:
   - **Одобрить** - подтвердить документ
   - **Отклонить** - отклонить документ с указанием причины:
     - Плохое качество
     - Несовпадение данных
     - Неверный тип документа
     - Отсутствуют страницы
     - Другое
3. После проверки документов вы можете заполнить поля:
   - СНИЛС
   - Серия паспорта
   - Номер паспорта
   - Дополнительные баллы
4. Нажмите "Сохранить данные"

**Важно**: Абитуриент увидит причину отклонения документа и сможет загрузить исправленную версию.

#### Все документы

В разделе **"Все документы"** отображаются все загруженные документы всех абитуриентов с возможностью фильтрации и поиска.

**Примечание**: Если абитуриент загрузил документ повторно, отображается только последняя версия каждого типа документа.

### Управление заявлениями

#### Просмотр заявлений по направлениям

1. Перейдите в раздел **"Статусы заявлений"**
2. Вы увидите список всех направлений, по которым есть заявления
3. Нажмите "Просмотреть заявления" для выбранного направления

#### Просмотр заявлений по направлению

На странице заявлений по направлению:
- Сначала отображаются заявления со статусом **"на проверке"** (выделены жёлтым)
- Затем остальные заявления
- Для каждого заявления отображается:
  - ID заявления
  - Дата подачи
  - ФИО абитуриента
  - Email
  - Приоритет
  - Статус
- Нажмите "Открыть" для просмотра детальной информации

#### Изменение статуса заявления

1. Откройте детальную информацию о заявлении
2. Вы увидите:
   - Информацию об абитуриенте
   - Направления в заявлении
   - Текущий статус
3. Выберите новый статус:
   - На проверке
   - Принято
   - Отклонено
4. Нажмите "Сохранить"

### Запросы и поиск

В разделе **"Запросы"** доступны следующие типы запросов:

#### 1. Все абитуриенты, подавшие документы

Показывает список всех абитуриентов, у которых есть загруженные документы.

#### 2. Поиск по ФИО/ID

1. Выберите тип запроса "Поиск по ФИО/ID"
2. Введите ФИО (можно частично) или ID абитуриента
3. Нажмите "Выполнить запрос"

**Примеры поиска**:
- По ID: `11`
- По фамилии: `Иванов`
- По фамилии и имени: `Иванов Иван`
- По полному ФИО: `Иванов Иван Иванович`

#### 3. Контактные данные абитуриента

1. Выберите тип запроса "Контактные данные абитуриента"
2. Введите ФИО или ID абитуриента
3. Нажмите "Выполнить запрос"

Результат покажет телефон и email выбранного абитуриента.

#### 4. По периоду подачи документов

1. Выберите тип запроса "По периоду подачи документов"
2. Укажите дату начала и дату окончания
3. Нажмите "Выполнить запрос"

Результат покажет всех абитуриентов, которые загрузили документы в указанный период.

#### 5. По специальности/направлению

1. Выберите тип запроса "По специальности/направлению"
2. Выберите направление подготовки из списка
3. Нажмите "Выполнить запрос"

Результат покажет всех абитуриентов, подавших заявления на выбранное направление.

#### 6. С достижениями (ГТО, волонтёрство)

1. Выберите тип запроса "С достижениями (ГТО, волонтёрство)"
2. Нажмите "Выполнить запрос"

Результат покажет всех абитуриентов, у которых есть:
- Загруженные документы о достижениях
- Зарегистрированные достижения типа ГТО или волонтёрство

Для каждого абитуриента отображаются его достижения.

### Работа с результатами запросов

После выполнения запроса:
- Результаты отображаются в таблице
- Для каждого абитуриента доступна ссылка "Просмотреть документы"
- Вы можете перейти к проверке документов абитуриента

## Часто задаваемые вопросы

### Для абитуриентов

**Q: Почему я не могу подать заявление?**
A: Подача заявлений доступна только после прохождения верификации. Убедитесь, что все три обязательных документа (паспорт, СНИЛС, образование) имеют статус "Подтверждён".

**Q: Что делать, если документ был отклонён?**
A: Просмотрите причину отклонения в разделе "Верификация" и загрузите исправленный документ. Предупреждение об отклонении исчезнет автоматически после подтверждения новой версии.

**Q: Можно ли отозвать заявление?**
A: Да, вы можете отозвать заявление, нажав кнопку "Отозвать" в разделе "Мои заявления". Внимание: это действие удаляет заявление полностью и не может быть отменено.

**Q: Сколько заявлений я могу подать?**
A: Вы можете подать несколько заявлений на разные направления с разными приоритетами.

### Для специалистов

**Q: Как найти абитуриента?**
A: Используйте раздел "Запросы" для поиска по ФИО, ID, направлению или другим критериям.

**Q: Что делать, если абитуриент загрузил документ повторно?**
A: В разделе проверки документов отображается только последняя версия каждого типа документа. Старые версии автоматически скрываются.

**Q: Как изменить статус заявления?**
A: Перейдите в раздел "Статусы заявлений", выберите направление, откройте нужное заявление и измените статус.

**Q: Где посмотреть все заявления по направлению?**
A: В разделе "Статусы заявлений" сначала выберите направление, затем вы увидите все заявления по этому направлению. Заявления со статусом "на проверке" отображаются первыми.
